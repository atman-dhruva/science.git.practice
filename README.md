# Science Git Training — practice repository

This is the **practice repository** for the GitHub Basics for Sciences training.
It is a sandbox. Nothing in it is real work, and nothing you do here affects
anyone else.

## How to get your own copy

Click the green **Use this template** button at the top of this page, then
**Create a new repository**.

- **Owner:** your own account
- **Repository name:** leave the suggested name
- Click **Create repository**

You now own a complete copy. Break whatever you like in it.

> A template copy gives you the **files** with a **fresh history**. The commit
> history of this repository is not carried across. That is different from
> *cloning*, which brings the whole history — you will do that in Module 1.4.

## The one habit worth building

**Work on a branch, not on `main`.**

In this practice copy you own everything, so nothing can go wrong. The habit
matters later, on shared repositories where `main` is protected and changes
arrive by review.

## Ground rules for the training

- You cannot break anything that matters
- You cannot affect anyone else
- If something looks confusing or risky, stop and ask rather than guessing
