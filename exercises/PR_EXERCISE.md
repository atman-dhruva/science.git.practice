# PR Exercise — Session 3A

Your hands-on exercise for Session 3A: Merging and Pull Requests.

---

## Exercise 1: Make your change

1. Bring `main` into your branch (Command Palette → `Git: Fetch`, then
   Command Palette → `Git: Merge Branch` → `origin/main`).
2. **Claim one numbered slot below** and put your name and answer on that line.
3. Stage, commit (e.g. *"Add favourite Canterbury spot"*), and push.
4. Wait for the facilitator's demo before opening a PR.

> Everyone edits a **different line**, so this exercise will not produce a
> conflict. Conflicts are Session 3B, and they are deliberate there.

## Exercise 2: Open your PR and merge

1. Go to GitHub and create a Pull Request from your branch into `main`.
2. Write a clear **title** and **description** — what changed, why, any notes.
3. Click **Files changed** and read your own diff (green = added, red = removed).
4. Open a buddy's PR, read their diff, and leave **one comment**.
5. Merge your PR using **Squash and merge**.
